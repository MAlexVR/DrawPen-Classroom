# Windows x64 edition

## Status

The Windows package is an unofficial community build of DrawPen Classroom Edition. It contains the classroom tools from the Fedora 44 COSMIC edition, while all X11/COSMIC-specific behavior is disabled by platform checks.

Build environment:

- GitHub-hosted Windows Server 2022 x64 runner
- Node.js 22.x
- Electron 40.4.0
- Electron Forge 7.11.2
- Squirrel.Windows installer and portable ZIP

The target is Windows 10 or Windows 11 on x64 hardware. Functional testing on a teacher's physical Windows device is still recommended before classroom deployment.

## Downloads

The Windows release provides:

- `DrawPen-Classroom-Windows-x64.Setup.exe`: per-user Squirrel installer.
- `DrawPen-win32-x64-0.0.56.zip`: portable packaged application.
- `DrawPenClassroom-0.0.56-full.nupkg` and `RELEASES`: Squirrel update metadata.
- `SHA256SUMS-windows-x64.txt`: checksums generated by the Windows build runner.

## Installation

1. Download the installer and `SHA256SUMS-windows-x64.txt` from the same GitHub Release.
2. Verify the checksum in PowerShell:

   ```powershell
   Get-FileHash .\DrawPen-Classroom-Windows-x64.Setup.exe -Algorithm SHA256
   ```

3. Compare the result with the checksum file.
4. Run the installer as your normal user.
5. Launch **DrawPen Classroom** from the Start menu.

Squirrel installs the application per user and normally does not require administrator privileges.

## Unsigned-build warning

This community build is not digitally signed because this repository does not have a Windows code-signing certificate. Windows SmartScreen can therefore report an unknown publisher. Verify the SHA-256 checksum and GitHub Release source before choosing to run it. Do not disable SmartScreen globally.

## Coexistence with official DrawPen

The installer, shortcut, executable, taskbar identity, and user-data directory use the name **DrawPen Classroom**. This helps avoid overwriting or sharing settings with the official DrawPen application.

## Verification performed by CI

The Windows workflow:

1. Installs the locked project dependencies on a Windows x64 runner.
2. Packages the application and creates Squirrel and ZIP artifacts.
3. Starts the packaged executable and confirms that it remains running for a short smoke-test interval.
4. Stops the test process.
5. Generates SHA-256 checksums and uploads the artifacts.

The smoke test verifies packaging and startup, but it cannot replace manual testing of drawing, pointer pass-through, global shortcuts, multi-monitor layouts, screenshots, or pen/stylus input on physical Windows hardware.
